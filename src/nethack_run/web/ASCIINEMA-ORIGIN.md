# asciinema player

The dashboard vendors asciinema-player **3.18.0** from the official release:
https://github.com/asciinema/asciinema-player/releases/tag/v3.18.0

- `asciinema-player.min.js`
- `asciinema-player.css`
- `ASCIINEMA-LICENSE` (Apache License 2.0, from the release's source tag)

Assets are served locally; replay playback does not contact a CDN or publish
recordings to asciinema.org. The player supports the exported asciicast v3 format.
